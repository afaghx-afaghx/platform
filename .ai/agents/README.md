# AFAGHX AI Agent System

AFAGHX intentionally uses **one logical engineering agent**:

**AFX-AI-CEA-001 — AFAGHX Chief Engineering Agent**

The four engineering teams are review perspectives inside this agent, not separate autonomous agents. This avoids fragmented architectural authority and prevents conflicting implementations.

The agent is governed by:
- AGENTS.md
- .ai/command-center.yaml
- .ai/agents/afaghx-chief-engineering-agent.md
- architecture documents under .ai/architecture/
- contracts under .ai/contracts/
- evidence schema under .ai/evidence/

No agent output is final merge authority.
