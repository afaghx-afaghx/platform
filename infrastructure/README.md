# Infrastructure Boundary

Infrastructure provides reproducible runtime and trust services: containers, Kubernetes, Terraform, network, CDN/WAF, monitoring, logging, tracing, secrets, KMS, backup, disaster recovery and security operations.

Application code must consume secrets and cryptographic operations through explicit interfaces. Production credentials and private keys never enter source control.

KMS is a first-class boundary for key lifecycle and rotation; rotation evidence must be generated by CI/operations rather than asserted in documentation.
