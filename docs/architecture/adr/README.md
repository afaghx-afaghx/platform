# Architecture Decision Records

ADRs record structural architecture decisions.

## Required sections
Every ADR must contain:
- Status
- Context
- Decision
- Consequences
- Alternatives

## Lifecycle
- **Proposed** — decision is under review.
- **Accepted** — decision governs implementation.
- **Superseded** — replaced by a later ADR.

Structural changes require an ADR before implementation. ADRs do not override `AGENTS.md`.
