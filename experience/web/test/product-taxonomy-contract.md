# AFAGHX Product Taxonomy v1.2

The homepage search category selector is a presentation registry for the **34 approved product baskets** defined for the AFAGHX Experience shell.

Each basket has:
- a stable slug used by the search request as `category`;
- a Persian display name for the FA experience;
- an English display name for the EN experience;
- exactly one self-owned basket key in the presentation registry.

The Experience Layer does not own the authoritative domain taxonomy. The canonical API/Domain layer remains the source of truth when the product/catalog search contract is promoted from prototype to production.

No additional product basket may be introduced in the homepage Experience without an explicit taxonomy contract update and corresponding test/evidence change.
