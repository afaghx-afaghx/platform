# AFX-PLATFORM

Shared platform capabilities consumed by domains and experience layers.

## Boundaries
- API gateway and API lifecycle
- Event backbone and delivery
- Notifications
- Search abstraction and projections
- File/object storage boundary
- Workflow/orchestration
- Billing/usage primitives
- Integrations
- Observability and operational adapters

Platform capabilities are reusable infrastructure, not business-domain authorities. They must consume AFX-CORE security context and preserve tenant scope.
